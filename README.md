# Figure Extractor for PPTX

PowerPoint のスライドから、図形・画像・グループ・表・グラフなどのオブジェクトをクリックで選び、
それぞれを 1 枚の図（png / tif / bmp / jpg）として指定のフォルダに一括保存するローカル Web アプリです。

## 使い方

1. 起動する
   - Mac: `run.command` をダブルクリック（初回は仮想環境を作ってパッケージを入れます）
   - Windows: `run.bat` をダブルクリック
   - 手動: `pip install -r requirements.txt` のあと `python app.py`
   ブラウザで http://127.0.0.1:8790 が開きます（使用中なら次の空いているポート。ターミナルに表示されます）。
2. 「pptx を開く」で選ぶか、画面にドロップする
3. スライド上のオブジェクトを選ぶ（選ぶとオレンジの枠と選択順の番号が付く）
   | 操作 | 動作 |
   |---|---|
   | クリック | そのオブジェクトだけを選ぶ |
   | 同じ場所をもう一度クリック／⌥(Alt)+クリック | 重なっている下のオブジェクトに切り替える（⌘+⌥ で追加） |
   | ⌘ / Ctrl / Shift + クリック | 追加・解除（別のスライドのものも追加できる） |
   | ドラッグ | 範囲に完全に入ったオブジェクトを選ぶ（⌘ 等を押しながらで追加） |
   | ⌥(Alt)+ドラッグ | 囲んだオブジェクトをまとめて 1 枚の図にする（⌘+⌥ で追加） |
   | ⌘A / Esc / ⌘Z | このスライドを全選択 / すべて解除 / 選択を戻す |
   | ← → / PageUp PageDown | スライドの移動 |
4. 右の一覧に選んだ順に並ぶ（1 行が 1 枚の図）。
   複数のオブジェクトを 1 枚の図にするときは、行をチェックして「チェックした n 個を 1 枚にまとめる」
   （チェックが無ければ「全部を 1 枚にまとめる」、⌘G でも可）。まとめた行の「分ける」で 1 個ずつに戻る。
   まとめられるのは同じスライドのオブジェクトだけ。重なり順と位置はスライドのとおりに保たれる。
   名前（初期値 fig1, fig2, …）と拡張子を自由に変える
   （変えた名前はオブジェクトごとに覚えていて、選び直しても戻る）
5. 保存先フォルダ（「参照…」でダイアログ）・解像度・背景の透明化を選んで「一括保存」
   同名のファイルがあるときは上書きするかを聞きます。

## 仕組み

- 描画は PowerPoint 自身に任せる（Mac は AppleScript、Windows は COM）。無ければ LibreOffice。
  環境変数 `FX_RENDERER=powerpoint|libreoffice` で固定できます。
- 選んだオブジェクトごとに「そのオブジェクトだけを載せたスライド」を白背景と黒背景の 2 枚ずつ作って
  PDF にし、2 枚の差から不透明度と描かれている範囲を求めて、余白なしで切り出します。
  影・線の太さ・矢印の先・回転も含めて切り出され、白い図形でも範囲が取れます。
- 元のファイルは変更しません。作業ファイルは OS の一時フォルダ（`figure-extractor-pptx/`）に置き、1 日で消えます。

## 制限

- 選べるのはスライドの最上位のオブジェクト（グループの中の 1 個だけは選べない）。
- 当たり判定はオブジェクトの枠（四角）で行うので、上に重なった文字のないテキストボックスなどがあると、
  最初のクリックではそちらが選ばれる。もう一度クリックすると下のオブジェクトに切り替わる。
- スライドの枠からはみ出した部分は切れます。
- 描画は PDF 経由のため、PowerPoint の「図として保存」と細部（フォントの描画など）がわずかに違うことがあります。
- Mac では、変換のあいだ PowerPoint に一時ファイルが一瞬開きます。

## 必要なもの

- Python 3.10 以上
- Microsoft PowerPoint（Mac / Windows）または LibreOffice
